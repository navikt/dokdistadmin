# Dokdistadmin
Tenesta tilbyr eit sett med operasjonar som blir nytta for å opprette, hente eller oppdatere sendingar i dokumentdistribusjon-databasa. 
Brukarane av tenestene er andre applikasjonar i distribusjonsdomenet.

Du finn meir informasjon om [REST-endepunkta på Confluence](https://confluence.adeo.no/pages/viewpage.action?pageId=314060469).
